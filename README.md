# 🛡 Cyber Threat Analyzer

A Flask-based **Cyber Threat Intelligence Dashboard** that analyzes cybersecurity news, extracts organizations and CVEs, calculates risk information, and visualizes the results through an interactive web interface.

The application provides an intuitive dashboard for monitoring cyber threats, viewing affected companies, tracking CVEs, searching articles, filtering by risk level, and exporting reports.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/nagihanylmzr/CyberThreatAnalyzer.git
```

Move into the project directory

```bash
cd CyberThreatAnalyzer
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```text
http://127.0.0.1:5000
```
