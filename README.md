# Cyber Threat Analyzer

Cyber Threat Analyzer is an open-source Python project that collects cybersecurity news from public sources, extracts useful information using Natural Language Processing (NLP), classifies cyber threats, and generates structured reports.

## Features

- Collect cybersecurity news
- Extract organizations and companies using spaCy
- Classify news by threat category
- Store data in SQLite
- Export CSV and JSON reports
- Interactive dashboard (planned)

## Technologies

- Python
- Requests
- BeautifulSoup
- spaCy
- SQLite
- Pandas
- Streamlit
- Matplotlib
